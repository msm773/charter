# Charter — Agent Context Manager

*One trusted context for every AI agent on your project.*

AI agents can do remarkable work, but a new session doesn't automatically inherit the decisions, constraints, and lessons from earlier work. Across long-running projects, sessions change, conversations are compacted, and different agents can end up working from different assumptions.

Charter is a small, local, version-controlled home for the decisions that govern a software project. Agents can retrieve that governing context and propose changes to it; you review and approve what becomes authoritative. Charter can provide context and ask agents to use it, but it cannot guarantee an agent will follow it.
